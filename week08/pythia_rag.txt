pythia_rag.py · Εβδομάδα 8
========================================

ΤΙ ΚΑΝΕΙ
Εβδομάδα 7-8: κοινές συναρτήσεις για RAG. Διάβασμα εγγράφων, καθάρισμα, κομμάτια, αναζήτηση, απάντηση.

Το χρησιμοποιούν τα scripts των εβδομάδων 7 και 8 (ίδιο αρχείο με την εβδομάδα 7).

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week08
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week08

Δεν το τρέχετε μόνο του. Είναι «βιβλιοθήκη»: το χρησιμοποιούν τα answer_cache.py, app_safe.py, attack_demo.py, check.py, cite.py, eval_answers.py, idk_demo.py, ingest.py, pipeline_demo.py, pythia_arch.py, pythia_safe.py, scan_docs.py.

ΤΙ ΧΡΕΙΑΖΕΤΑΙ
- Κλειδί Anthropic στο αρχείο .env (C:\ai4dev\.env ή ~/ai4dev/.env). Δείτε το README, ενότητα «Κλειδιά».
- Το Ollama ανοιχτό, για τοπικά μοντέλα ή embeddings (ollama list για έλεγχο).
