Διάλεξη 15: «δεν ξέρω». Ερωτήσεις που ΔΕΝ απαντώνται από τα έγγραφα, με και χωρίς κατώφλι.

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week08
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week08

Μετά:
  python idk_demo.py
  python idk_demo.py --threshold 7
