ΤΙ ΚΑΝΕΙ
Διάλεξη 15: η Πυθία ως API, με άμυνες. Έλεγχος εγγράφων στο ανέβασμα, παραπομπές και «δεν ξέρω» στην απάντηση.
API με άμυνες: uvicorn app_safe:app --reload

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week08
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week08

Μετά:
  uvicorn app_safe:app --reload
  και στον browser: http://127.0.0.1:8000/docs

- Το Ollama ανοιχτό, για τοπικά μοντέλα ή embeddings (ollama list για έλεγχο).
