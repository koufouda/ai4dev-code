pythia_models.py · Εβδομάδα 10
========================================

ΤΙ ΚΑΝΕΙ
Εβδομάδα 10, διάλεξη 20: κοινές συναρτήσεις για τη σύγκριση μοντέλων (cloud και τοπικά, μέσω LiteLLM).
Κοινές συναρτήσεις: λίστα μοντέλων, κλήση με χρόνο και κόστος, Ollama API

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week10
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week10

Δεν το τρέχετε μόνο του. Είναι «βιβλιοθήκη»: το χρησιμοποιούν τα compare_models.py, local_models.py, speed_test.py.

ΤΙ ΧΡΕΙΑΖΕΤΑΙ
- Κλειδί Anthropic στο αρχείο .env (C:\ai4dev\.env ή ~/ai4dev/.env). Δείτε το README, ενότητα «Κλειδιά».
- Το Ollama ανοιχτό, για τοπικά μοντέλα ή embeddings (ollama list για έλεγχο).
