ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week10
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week10

Μετά:
  τον ξεκινά ο client (δεν τον τρέχετε μόνοι σας).
  Δοκιμή με το MCP Inspector:  mcp dev pythia_mcp_server.py
