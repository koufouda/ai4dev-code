Διάλεξη 13: πώς κόβουμε ένα έγγραφο σε κομμάτια (chunks).
Πώς κόβουμε σε κομμάτια (--naive, --size, --overlap, --file)

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week07
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week07

Μετά:
  python chunk_demo.py                    (κομμάτια με προτάσεις, 800 χαρακτήρες, overlap 150)
  python chunk_demo.py --size 400
  python chunk_demo.py --naive            (κόψιμο κάθε 800 χαρακτήρες, όπου κι αν πέσει)
  python chunk_demo.py --file docs/Oroi_Polisis.docx
