# AI for Developers · κώδικας μαθήματος

ΚΕΔΙΒΙΜ Οικονομικού Πανεπιστημίου Αθηνών · διδάσκων Γιάννης Κουφουδάκης

Εδώ είναι ο κώδικας κάθε εβδομάδας. Σε όλο το πρόγραμμα χτίζουμε την ίδια εφαρμογή, την **Πυθία**: έναν βοηθό για ένα e-shop που απαντά πάνω σε ελληνικά έγγραφα, κάνει ενέργειες με εργαλεία και στο τέλος τρέχει στο cloud.

**Πρώτα:** [οδηγίες εγκατάστασης για Windows 11 και Linux](INSTALL.md) (και σε [Word](INSTALL.docx)).

| Φάκελος | Μαθήματα | Θέμα |
|---|---|---|
| `week01` | 1-2 | Πρώτη κλήση σε LLM, tokens, κόστος, τοπικά μοντέλα |
| `week05` | 9-10 | Prompting, structured outputs, αξιολόγηση |
| `week06` | 11-12 | Μνήμη συνομιλίας, embeddings |
| `week07` | 13-14 | RAG: έγγραφα, hybrid search, reranking |
| `week08` | 15-16 | Παραπομπές, «δεν ξέρω», ασφάλεια, αρχιτεκτονική |
| `week09` | 17-18 | Tool calling, workflows, agents |
| `week10` | 19-20 | MCP, ασφάλεια agents, ανοικτά μοντέλα |
| `week11` | 21-22 | Docker, CI, logs, GDPR και AI Act |
| `week12` | 23-24 | Εγκατάσταση στο cloud, τελικό project |

Οι εβδομάδες 2-4 (Python και FastAPI) γίνονται από άλλον διδάσκοντα.

## Πώς τρέχετε μια εβδομάδα

Αντιγράψτε τον φάκελο της εβδομάδας μέσα στον φάκελο του μαθήματος (π.χ. `C:\ai4dev\week06` ή `~/ai4dev/week06`) και ακολουθήστε το `README.md` του φακέλου. Κάθε φάκελος έχει `requirements.txt`, `.env.example` και `check.py`, που ελέγχει ότι όλα είναι στη θέση τους.

## Κλειδιά API

Τα κλειδιά μπαίνουν **μόνο** στο αρχείο `.env` στον υπολογιστή σας. Ποτέ σε commit, ποτέ σε κοινόχρηστο φάκελο, ποτέ στην οθόνη. Το `.gitignore` αυτού του repository αποκλείει το `.env`. Αν κάνετε fork, κρατήστε το έτσι.
