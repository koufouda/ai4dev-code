chat_memory.py · Εβδομάδα 6
========================================

ΤΙ ΚΑΝΕΙ
Διάλεξη 11: η Πυθία συνομιλεί με τρεις στρατηγικές μνήμης. Δείχνει tokens και κόστος σε κάθε γύρο.
Συνομιλία με --strategy full / window / summary, --auto, --budget

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week06
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week06

Μετά:
  python chat_memory.py                       (full: όλο το ιστορικό, γράφετε εσείς)
  python chat_memory.py --auto                (οι ερωτήσεις από το conversation.txt)
  python chat_memory.py --auto --strategy window
  python chat_memory.py --auto --strategy summary
  python chat_memory.py --budget 0.01         (σταματά όταν το κόστος ξεπεράσει το όριο)
  python chat_memory.py --local               (τοπικό μοντέλο)
  Γράψτε «τέλος» για έξοδο.

ΤΙ ΧΡΕΙΑΖΕΤΑΙ
- Κλειδί Anthropic στο αρχείο .env (C:\ai4dev\.env ή ~/ai4dev/.env). Δείτε το README, ενότητα «Κλειδιά».
- Το Ollama ανοιχτό, για τοπικά μοντέλα ή embeddings (ollama list για έλεγχο).
