cache_demo.py · Εβδομάδα 6
========================================

ΤΙ ΚΑΝΕΙ
Διάλεξη 11: prompt caching. Ο ίδιος μεγάλος κατάλογος σε τρεις ερωτήσεις.

Η πρώτη κλήση γράφει τον κατάλογο στην cache του παρόχου. Οι επόμενες τον διαβάζουν από εκεί:
πιο φθηνά και πιο γρήγορα. Η cache ζει περίπου 5 λεπτά.
Prompt caching με τον κατάλογο προϊόντων

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week06
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week06

Μετά:
  python cache_demo.py
  python cache_demo.py --no-cache     (το ίδιο χωρίς cache, για σύγκριση)

ΤΙ ΧΡΕΙΑΖΕΤΑΙ
- Κλειδί Anthropic στο αρχείο .env (C:\ai4dev\.env ή ~/ai4dev/.env). Δείτε το README, ενότητα «Κλειδιά».
- Το Ollama ανοιχτό, για τοπικά μοντέλα ή embeddings (ollama list για έλεγχο).
