growth.py · Εβδομάδα 6
========================================

ΤΙ ΚΑΝΕΙ
Διάλεξη 11: πόσο μεγαλώνει το κόστος μιας συνομιλίας, γύρο-γύρο. ΔΕΝ καλεί μοντέλο.

Μετρά τα tokens που θα στέλναμε σε κάθε γύρο με τρεις στρατηγικές μνήμης:
  full    = όλο το ιστορικό
  window  = μόνο τα 6 τελευταία μηνύματα
  summary = σύνοψη των παλιών και τα 4 τελευταία
Πόσα tokens στέλνει κάθε γύρος, με τρεις στρατηγικές (χωρίς κλήση σε μοντέλο)

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week06
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week06

Μετά:
  python growth.py
  python growth.py --turns 50

ΤΙ ΧΡΕΙΑΖΕΤΑΙ
- Κλειδί Anthropic στο αρχείο .env (C:\ai4dev\.env ή ~/ai4dev/.env). Δείτε το README, ενότητα «Κλειδιά».
- Το Ollama ανοιχτό, για τοπικά μοντέλα ή embeddings (ollama list για έλεγχο).
