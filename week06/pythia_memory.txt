ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week06
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week06

Δεν το τρέχετε μόνο του. Είναι «βιβλιοθήκη»: το χρησιμοποιούν τα app_chat.py, cache_demo.py, chat_memory.py, check.py, context_limit.py, forget.py, growth.py.
