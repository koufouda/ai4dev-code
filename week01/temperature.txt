temperature.py · Εβδομάδα 1
========================================

ΤΙ ΚΑΝΕΙ
Διάλεξη 2: η ίδια ερώτηση 4 φορές με temperature 0, 1, 1,5 και 2.

Τρέχει στο τοπικό μοντέλο (MODEL_LOCAL), γιατί τα νεότερα Claude δέχονται μόνο temperature=1.
Η ίδια ερώτηση με temperature 0 και 1

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week01
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week01

Μετά:
  python temperature.py "Δώσε ένα όνομα για ένα καφέ στην Πλάκα."

ΤΙ ΧΡΕΙΑΖΕΤΑΙ
- Κλειδί Anthropic στο αρχείο .env (C:\ai4dev\.env ή ~/ai4dev/.env). Δείτε το README, ενότητα «Κλειδιά».
- Το Ollama ανοιχτό, για τοπικά μοντέλα ή embeddings (ollama list για έλεγχο).
