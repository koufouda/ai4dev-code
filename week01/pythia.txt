pythia.py · Εβδομάδα 1
========================================

ΤΙ ΚΑΝΕΙ
Διάλεξη 2: το ίδιο μοντέλο με τρεις «προσωπικότητες». Αλλάζει μόνο το system prompt.
Συνομιλία με μία από τρεις περσόνες: python pythia.py 1 (Βοηθός), 2 (Πυθία, προεπιλογή), 3 (Senior dev)

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week01
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week01

Μετά:
  python pythia.py        (Πυθία, η προεπιλογή)
  python pythia.py 1      (Βοηθός)
  python pythia.py 3      (Senior dev)
  Γράψτε «τέλος» για έξοδο.

ΤΙ ΧΡΕΙΑΖΕΤΑΙ
- Κλειδί Anthropic στο αρχείο .env (C:\ai4dev\.env ή ~/ai4dev/.env). Δείτε το README, ενότητα «Κλειδιά».
