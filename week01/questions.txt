=== Κόψιμο internet ΜΟΝΟ σε αυτό το terminal (το Teams δεν επηρεάζεται) ===
Windows, Command Prompt (cmd, π.χ. το terminal του PyCharm):
set HTTPS_PROXY=http://127.0.0.1:9
set HTTP_PROXY=http://127.0.0.1:9
set NO_PROXY=localhost,127.0.0.1
set LITELLM_LOCAL_MODEL_COST_MAP=True
Windows (PowerShell, η γραμμή ξεκινά με PS):
$env:HTTPS_PROXY="http://127.0.0.1:9"; $env:HTTP_PROXY="http://127.0.0.1:9"; $env:NO_PROXY="localhost,127.0.0.1"; $env:LITELLM_LOCAL_MODEL_COST_MAP="True"
Mac / Linux:
export HTTPS_PROXY=http://127.0.0.1:9 HTTP_PROXY=http://127.0.0.1:9 NO_PROXY=localhost,127.0.0.1 LITELLM_LOCAL_MODEL_COST_MAP=True
(Για να ξαναποκτήσει internet: κλείστε το terminal και ανοίξτε νέο.)
