remote_eval.py · Εβδομάδα 12
========================================

ΤΙ ΚΑΝΕΙ
Διάλεξη 23: το σύνολο δοκιμών ΠΑΝΩ στην εγκατεστημένη εφαρμογή. Σωστές απαντήσεις, χρόνος (p50, p95), σφάλματα.
Ό,τι μετρήσατε στο laptop, το ξαναμετράτε εκεί που θα τη χρησιμοποιήσουν: αλλάζουν δίκτυο, μνήμη, ρυθμίσεις.
Το σύνολο δοκιμών πάνω στην εγκατεστημένη εφαρμογή: σωστά, p50/p95, σφάλματα

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week12
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week12

Μετά:
  python remote_eval.py https://pythia.example.com
  python remote_eval.py http://localhost:8000 --min 0.7
  (Αν η εφαρμογή έχει APP_TOKEN: πρώτα  $env:APP_TOKEN="..."  στο ίδιο terminal.)

ΤΙ ΧΡΕΙΑΖΕΤΑΙ
- Κλειδί Anthropic στο αρχείο .env (C:\ai4dev\.env ή ~/ai4dev/.env). Δείτε το README, ενότητα «Κλειδιά».
- Το Ollama ανοιχτό, για τοπικά μοντέλα ή embeddings (ollama list για έλεγχο).
