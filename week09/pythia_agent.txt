ΤΙ ΚΑΝΕΙ
Εβδομάδα 9, διάλεξη 18: ο agent. Ο βρόχος σκέψη → ενέργεια → παρατήρηση, με όρια.

Χτίζει πάνω στο pythia_tools.py (διάλεξη 17).
Ο agent με σκέψη και όρια, και ένα σταθερό workflow για σύγκριση

ΠΩΣ ΤΟ ΤΡΕΧΕΤΕ
Σε κάθε νέο τερματικό, πρώτα:
  Windows:  cd C:\ai4dev  ->  .venv\Scripts\activate  ->  cd week09
  Linux:    cd ~/ai4dev  ->  source .venv/bin/activate  ->  cd week09

Δεν το τρέχετε μόνο του. Είναι «βιβλιοθήκη»: το χρησιμοποιούν τα agent_demo.py, agent_limits.py, agent_vs_workflow.py, eval_agent.py, extra_tool.py.

ΤΙ ΧΡΕΙΑΖΕΤΑΙ
- Κλειδί Anthropic στο αρχείο .env (C:\ai4dev\.env ή ~/ai4dev/.env). Δείτε το README, ενότητα «Κλειδιά».
- Το Ollama ανοιχτό, για τοπικά μοντέλα ή embeddings (ollama list για έλεγχο).
